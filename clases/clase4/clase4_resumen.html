Clase 4 – Punteros y Structs

Organizar sensores en structs, pasar por referencia, array de sensores

¿Qué vamos a ver hoy?

Repaso express 1-3: Clase 1 = variables/tipos, Clase 2 = if/switch para alertas, Clase 3 = for/millis()/Serial 9600 con DHT11 real y dashboard CSV. Hasta ahora usamos variables sueltas para cada sensor. Hoy aprendemos a agrupar datos relacionados en struct y a usar punteros para pasar sensores por referencia sin copiar datos (clave en Arduino con 2KB RAM).

Al final tendremos un array de sensores que la estación recorre con for (Clase 3) para leer, promediar y alertar con if (Clase 2), enviando todo por Serial 9600 al mismo dashboard de la clase pasada.

Temario

  • Bloque 1 – struct Sensor: agrupar pin, tipo, valor, umbral, nombre
  • Bloque 2 – Punteros: &, *, paso por referencia, funciones que modifican sensores
  • Bloque 3 – Array de structs: recorrer sensores, leer todos, alertar todos, menú dinámico

Hardware: mismo kit + 2 sensores nuevos
